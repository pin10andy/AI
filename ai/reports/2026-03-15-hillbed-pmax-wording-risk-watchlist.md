# Hillbed Purchase PMax Wording Risk Watchlist

## Purpose

這份 watchlist 用來輔助 `hillbed-purchase-pmax` 的 human review，
把常見 wording 分成：

- 可直接用
- 可用但需人工確認語境
- 不可用

它不是取代 human review，而是讓 reviewer 有一致的判準。

## Scope

- 產品：山丘樂眠床
- Lane：purchase PMax
- 使用情境：output 生成、rerun、production 變更審查

## Tier 1: 可直接用

這些表述目前可視為低風險，但仍需和實際產品事實一致：

| Phrase Pattern | 用法說明 | 備註 |
|---------------|---------|------|
| 支撐更穩定 | 描述結構與睡感 | 避免延伸成醫療效果 |
| 包覆更剛好 | 描述感受 | 可搭配材質事實 |
| 睡感更安定 | 描述體驗 | 不宣稱治療 |
| 100天安心睡 | 穩定承諾 | 必須和官網一致 |
| 10年保固 | 穩定承諾 | 必須和官網一致 |
| 第2張床 | 使用情境 | 可作為 smart-start angle |
| 入門不將就 | 價值定位 | 不可寫成最低價 |

## Tier 2: 可用但需人工確認語境

這些表述容易靠近政策邊界。可用，但 reviewer 需確認它們仍是感受描述，而不是醫療承諾：

| Phrase Pattern | 風險點 | 建議處理 |
|---------------|-------|---------|
| 接住身體 | 容易被讀成改善身體狀態 | 旁邊補材質或支撐事實，避免單獨強打 |
| 托住腰背 | 靠近腰痛改善暗示 | 避免和「改善」「舒緩」直接連用 |
| 腰背慢慢放鬆 | 若和症狀字眼連用會升高風險 | 保留在感受層，不寫成療效 |
| 睡出放鬆感 | 容易被延伸成效果承諾 | 不可接「立刻」「明顯改善」 |
| 選床少一點壓力 | 心理感受可接受 | 不可變成保證不踩雷 |
| 安心試睡 | 可接受 | 必須和 100 天安心睡事實一致 |

## Tier 3: 不可用

以下表述視為 production lane 禁用：

| Phrase Pattern | 原因 | 建議替代 |
|---------------|------|---------|
| 保證治好腰痛 | 醫療承諾 | 改寫為「支撐更穩定」 |
| 睡一晚立刻不痠痛 | 立即效果 + 症狀承諾 | 改寫為「睡感更安定」 |
| 改善脊椎問題 | 醫療暗示 | 改寫為「支撐與包覆更平衡」 |
| 醫療級治療效果 | 醫療宣稱 | 改寫為產品材質與認證事實 |
| 全台最低價 | 價格絕對化 | 改寫為「14,900起的入門定位」 |
| 一躺就知道最適合你 | 絕對化結果承諾 | 改寫為「先感受，再慢慢決定」 |

## Reviewer Checklist

每次遇到 Tier 2 或可疑新字句時，至少確認以下三點：

1. 是否仍可被解讀為「感受描述」而非「療效承諾」
2. 是否有對應的產品事實支撐，而不是只剩抽象形容
3. 是否會把價格或安心承諾擴散到不該承載的 angle

## Update Trigger

以下情況需要更新這份 watchlist：

- Google Ads 政策對身體感受/健康類措辭有新解釋
- human review 連續兩次指出相同風險字句
- 新 lane 引入新的 CTA 或體驗型語言
- 品牌新增或移除 forbidden claims
