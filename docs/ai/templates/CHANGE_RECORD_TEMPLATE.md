# CHANGE_RECORD_TEMPLATE

Canonical template: `ai/changes/change-template.md`

Suggested destination:

- `ai/changes/YYYY-MM-DD-short-change-name.md`

Usage notes:

- Change records are required for non-trivial work.
- Include touched files, assumptions, known risks, follow-ups, and validation evidence.
- Keep the canonical change template in `ai/changes/change-template.md`.
